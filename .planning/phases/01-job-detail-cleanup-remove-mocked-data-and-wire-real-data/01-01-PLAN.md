<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client -> GET /v1/job-event | Untrusted jobId query parameter from authenticated user |
| service -> job_events collection | Internal write path; events written by server-side services only |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Information Disclosure | GET /v1/job-event?jobId= | mitigate | JobEventPolicy.canRead verifies authUser.businessIds includes event.businessId; ForbiddenError thrown on mismatch |
| T-01-02 | Tampering | job_events collection | mitigate | No public write endpoint exposed; events only created server-side by JobEventCreator injected into authorized services |
| T-01-03 | Spoofing | GET /v1/job-event | mitigate | JwtAuthGuard on controller validates Firebase JWT; unauthenticated requests rejected with 401 |
| T-01-04 | Denial of Service | GET /v1/job-event?jobId= | accept | jobId is a single ObjectId string; query is indexed by jobId; low risk for sole trader workload |
| T-01-05 | Input Validation | jobId query param | mitigate | Validate jobId is a valid ObjectId string before querying; repository uses `new ObjectId(jobId)` which throws on invalid input, caught by controller try/catch |
</threat_model>
