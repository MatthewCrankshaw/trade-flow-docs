**3. Create `jobEventApi.ts`:**

```typescript
import { apiSlice } from "@/services/api";
import type { JobEvent, StandardResponse } from "@/types";

export const jobEventApi = apiSlice.injectEndpoints({
  endpoints: (builder) => ({
    getJobEvents: builder.query<JobEvent[], string>({
      query: (jobId) => `/v1/job-event?jobId=${jobId}`,
      transformResponse: (response: StandardResponse<JobEvent>) => response.data,
      providesTags: (result) =>
        result
          ? [...result.map(({ id }) => ({ type: "JobEvent" as const, id })), { type: "JobEvent", id: "LIST" }]
          : [{ type: "JobEvent", id: "LIST" }],
    }),
  }),
});

export const { useGetJobEventsQuery } = jobEventApi;
```

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-08 | Tampering | Inline event writes | mitigate | Events written only by server-side services after primary operation succeeds; no client-controlled event content; metadata is derived from server state (createdQuote.id, etc.) |
| T-01-09 | Repudiation | Event audit trail | accept | Events record what happened but don't include who triggered it (user ID not in event metadata); acceptable for v1 activity feed which is display-only |
| T-01-10 | Information Disclosure | Event metadata in timeline | accept | Metadata contains only IDs (quoteId, scheduleId) and status strings; no PII exposed; displayed to business owner who already has access to underlying entities |
</threat_model>
