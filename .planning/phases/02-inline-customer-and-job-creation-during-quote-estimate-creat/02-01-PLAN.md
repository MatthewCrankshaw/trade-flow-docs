<objective>
Add job title auto-generation to the backend so that when a job is created without an explicit title (inline creation from quote/estimate dialogs), the API generates a title using the pattern `{Job Type Name} - {Customer Name} #{N}` where N is a per-customer sequential number.

Purpose: Per D-11, inline job creation skips the title field to keep the form minimal (2 fields: customer + job type). The backend must generate a meaningful title automatically.

Output: Modified job-creator.service.ts with auto-title logic, new countByCustomerId repository method, and unit tests.
</objective>
