## Key Accomplishments

1. Job events system — full CRUD backend module with timeline event types for status changes, notes, and schedule events
2. Job detail page wired to real API data — removed all mock constants, unbuilt tabs, and stub UI
3. Inline event writes — quote, estimate, and schedule services automatically create job timeline events
4. Job title auto-generation — `{JobType} - {CustomerName} #{N}` pattern for inline job creation
5. InlineCustomerForm — name-only customer creation dialog with stacked dialog integration in CreateJobDialog
6. Full 3-level creation chain — quote/estimate -> new job -> new customer with auto-selection at every level

## Key Decisions

- Job events use a separate collection and module (not embedded in job document)
- Auto-title uses per-customer sequential numbering via countByCustomerId
- InlineCustomerForm defaults to customerType "individual" (most common for tradespeople)
- Removed customer prerequisite from Quotes/Estimates pages since inline creation makes it unnecessary
